# 1부 10화 — Nukas familie
## 누카의 가족

> **장면 1** 10월 17일 토요일 오후 2시. 아마게르, 대학 근처 누카의 작은 아파트. 그린란드식 커피 모임 카페믹(kaffemik). 식탁에는 케이크와 말린 생선, 벽에는 일루리사트의 빙산 사진. 요나스, 잉에르, 유수프가 손님으로 왔다. 그런데 누카는 휴대폰 뉴스를 보며 자꾸 표정이 어두워진다.

### 1. Nuka: Aluu! Velkommen. Kom indenfor. I behøver ikke banke på. Til kaffemik går man bare ind.
번역: 알루! 어서 와. 들어와. 노크 안 해도 돼. 카페믹엔 그냥 들어오는 거야.
■ 주요 단어
| aluu | aluu (그린란드어 감탄사) | 안녕 |
| velkommen | velkommen (형용사·감탄사) | 환영해 |
| indenfor | indenfor (부사, 위치) | 안에, 안으로 |
| behøver | behøve (동사) | ~할 필요가 있다 |
| banke på | banke på (동사구) | 노크하다 |
■ 문법
- I behøver ikke (at) banke på: behøve ikke = '~할 필요 없다'. 뒤에 at은 생략 가능.
- I: 2인칭 복수 주어(손님 여럿에게).
■ 표현
- Kom indenfor. — '안으로 들어와'. 손님 맞이 표현.
■ 시제·어순
- 명령형 Kom. Til kaffemik går man …: 전치사구 문두 → 동사 går → 주어 man(도치).
