# 2부 26화 — Pension ved 70?

> **장면 1** 2월 13일 토요일 오전 11시, Thomsens Cykler. 입대 후 첫 주말 휴가를 받은 에밀이 군복 차림으로 가게에 들른다. 머리는 짧게 깎였고 걸음걸이가 달라졌다. 잉에르는 커피를 들고 와서, 아버지의 '중요한 소식'이 무엇일지 요나스와 함께 추측한다.

### 1. Emil: [i uniform] Godmorgen, mester! Melder mig til tjeneste!
번역: [군복 차림으로] 좋은 아침입니다, 마이스터! 근무 신고합니다!
■ 주요 단어
| uniform | uniform (명사, en, -er) | 제복, 군복 |
| melder mig | melde sig (재귀동사) | 신고하다, 출두하다 |
| tjeneste | tjeneste (명사, en, -r) | 근무, 복무 |
■ 문법
- 주어 jeg를 생략한 군대식 말투: (Jeg) melder mig til tjeneste.
- melde sig: 재귀동사, 재귀대명사 mig.
■ 표현
- Melder mig til tjeneste — '복무 신고합니다'. 군대 용어를 장난스럽게 씀.
■ 시제·어순
- 현재형.

### 2. Jonas: Emil! Se dig! Du ligner en rigtig soldat. Hvad har de gjort ved dit hår?
번역: 에밀! 너 좀 봐! 진짜 군인 같다. 머리는 어떻게 된 거야?
■ 주요 단어
| se dig | se (명령형) + dig | 너 좀 봐 |
| ligner | ligne (동사) | …처럼 보이다, 닮다 |
| soldat | soldat (명사, en, -er) | 군인 |
| gjort ved | gøre ved | …에 (무엇을) 하다 |
| hår | hår (명사, et) | 머리카락 |
■ 문법
- ligne + 명사: '…같아 보이다'(전치사 없이 목적어).

■ 표현
- Se dig! — '너 좀 봐라!' 놀람·감탄.
■ 시제·어순
- har gjort: 현재완료 — 지금 보이는 결과(짧은 머리).

### 4. Inger: Jeg synes, at det klæder Dem, unge mand. De ser ti år ældre ud.

■ 주요 단어
| synes | synes (동사) | …라고 생각하다(의견) |
| klæder | klæde (동사) | 어울리다 |
| Dem | De → Dem | 당신(존칭 목적격) |
| ældre | gammel → ældre | 더 나이 든 |
■ 문법
- De/Dem: 격식 존칭 2인칭. 현대 덴마크어에선 드물고 노인 세대(잉에르)의 말투.

■ 표현
- det klæder dig — '너한테 잘 어울려'.
- synes vs. tro: synes는 개인적 평가·취향, tro는 사실 추측.
■ 시제·어순
- 현재형.

■ 주요 단어
| system | system (명사, et, -er) | 시스템 |
| laves | lave → laves (수동) | 만들어지다, 수리되다 |
| til venstre | venstre | 왼쪽에 |
| til højre | højre | 오른쪽에 |
■ 문법
- skal laves: 법조동사 + s-수동 부정사.
- skulle have været lavet: '…되었어야 했다'(이루어지지 않은 과거 의무). skulle(과거) + have været(완료 부정사) + lavet(분사)의 수동 완료.
- mit nye system: 소유대명사 뒤 형용사는 -e형.
■ 표현
- (특별한 관용 표현 없음)
■ 시제·어순
- 관계절이 주어를 길게 꾸미고 그 뒤 동사 står.
