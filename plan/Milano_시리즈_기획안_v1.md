# INCHIOSTRO E OMBRE — 밀라노 탐사보도 이탈리아어 대화문 시리즈 기획안

> **잉크와 그림자** — 진실을 쓰는 잉크와, 그것을 덮으려는 그림자의 싸움

| 항목 | 내용 |
|---|---|
| 배경 | 이탈리아 밀라노 (거점) + 이탈리아 각지 + 해외(스위스·몰타·두바이·네덜란드·튀니지·벨기에·프랑스) |
| 장르 | 탐사보도 스릴러 / 위장잠입 / 내부 스파이 색출 |
| 분량 | **8부 × 15화 = 총 120화**, 화당 **150턴** → 총 **18,000턴** |
| 형식 | 이탈리아어 대화문 (각 화 앞에 한국어 장면 설명 1~2줄) |
| 학습 설계 | 부가 진행될수록 시제·법·레지스터 난이도가 단계적으로 올라가도록 배치 |

## 1. 세계관과 큰 줄기

밀라노의 독립 탐사보도 매체 **Il Riflettore**(일 리플레토레, '스포트라이트'). 이솔라(Isola) 지구 오래된 인쇄소 2층에 편집국이 있다.

주인공 **루카 모레티**와 팀은 매 부마다 서로 다른 분야의 비리를 파헤친다. 공사장, 금융, 의료, 물류, 여론조작, 유럽 로비 등이다. 그런데 사건마다 같은 흔적이 남는다. 정치·금융·조직범죄·해외 세력이 얽힌 비공식 네트워크 **'Il Consorzio'(콘소르치오)**, 그리고 그 정점에 있는 금융가 **아우구스토 발렌티**다.

시리즈 전체를 관통하는 미스터리도 있다. 2016년 '교통사고'로 죽은 루카의 스승 기자 **알베르토 시로니**의 마지막 취재다. 각 부의 사건을 따라가면 결국 이 죽음에 닿는다.

### 시리즈 3대 축
1. **취재(Inchiesta)**: 문서·데이터·증인으로 진실을 쌓는다.
2. **위장잠입(Sotto copertura)**: 팀원이 조직 내부에 다른 신분으로 들어간다.
3. **역잠입 색출(Caccia alla talpa)**: 상대가 우리 쪽이나 협력기관에 심어 둔 사람을 잡아낸다.

→ 각 부에 최소 1회 **잠입**과 1회 **색출 또는 정체 발각 위기**를 넣는다.

## 3. 화(에피소드) 표준 구조 — 150턴

| 구간 | 턴 | 내용 |
|---|---|---|
| ① 콜드 오픈 | 1–10 | 긴장감 있는 짧은 장면, 또는 지난 화 클리프행어의 직후 |
| ② 장면 A | 11–45 | 편집국 회의나 정보원 접촉. 정보 정리와 목표 설정 |
| ③ 장면 B | 46–80 | 현장 취재나 인터뷰 (주로 Lei 레지스터) |
| ④ 장면 C | 81–115 | 잠입·추적·갈등. 화의 중심 사건 |
| ⑤ 장면 D | 116–140 | 반전이나 결정적 대화 |
| ⑥ 엔딩 훅 | 141–150 | 다음 화로 이어지는 단서나 위기 |

- 한 화에 **3~5개 장소**, 등장인물은 **장면당 2~4명**으로 묶어 학습자가 화자를 따라가기 쉽게 한다.
- 매 화 **tu 장면 1개 이상 + Lei 장면 1개 이상**을 넣어 레지스터 대비를 유지한다.
- 문자·전화·암호 채팅 장면은 턴을 짧게, 인터뷰와 심문은 턴을 길게 쓴다.

### 부(15화) 표준 구조
| 화 | 단계 |
|---|---|
| 1–3 | **발단**: 제보·사건 발생, 취재 착수 |
| 4–6 | **전개**: 구조 파악, 잠입 준비·투입 |
| 7–9 | **심화**: 내부 증거 확보, 중간 반전 |
| 10–12 | **위기**: 정체 발각 위험, 증인 이탈, 압박 |
| 13–14 | **절정**: 결정적 증거, 당사자 대면, 반론권 |
| 15 | **보도**: 기사 공개, 다음 부로 이어지는 떡밥 |

## 7. 집필 규칙 (대본 작성 시)

1. **턴 표기**: `번호. 화자: 대사` (기존 시리즈 분석 문서와 같은 형식)
2. 한 턴은 **1~3문장**. 독백이 길어지면 턴을 나눈다.
3. 각 장면 앞에 한국어로 **시간·장소·인물·장면 목적**을 1~2줄 적는다.
4. 화마다 해당 부의 **문법 초점이 최소 10턴 이상 자연스럽게** 등장하게 한다.
5. 성폭력·고문 같은 민감한 소재는 **결과와 증언 중심으로 절제해서** 다룬다.
6. 실존 인물과 기업은 쓰지 않는다. 실제 지명과 기관(검찰청, 재무경비대 등)은 쓴다.
