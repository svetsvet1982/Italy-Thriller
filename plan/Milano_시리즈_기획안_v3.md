## 2. 분야별 구성 방식

같은 탐사보도라도 분야가 다르면 **진실에 다가가는 길**이 다르다. 그래서 부의 구성 방식을 분야에 맞춘다.

| 분야 | 구성 방식 | 15화의 흐름 | 화의 리듬 | 대화 톤 |
|---|---|---|---|---|
| **사회** | **옴니버스 누적형** | 화마다 한 사람(피해자·목격자)의 이야기. 끝에서 하나의 구조로 꿰어진다 | 현장 → 사람 → 감정 → 단서 | 구어, 방언, tu, 감정 |
| **경제** | **돈줄 추적형** | 화마다 돈이 한 단계씩 이동한다 (회사 → 계좌 → 펀드 → 수익자) | 데이터 → 서류 → 내부자 → 대면 | 비즈니스 Lei, 숫자, 조건법 |
| **정치** | **D-day 카운트다운형** | 선거 D-60부터 개표일까지. 화마다 날짜가 줄어든다 | 밀담 → 캠프 → 보좌관 → 표결 | 고급 Lei, 완곡어법, 정치 수사 |
| **사법·감시** | **밀실 심리전형** | 편집국 안에서 용의자 한 명당 한 화 | 추리 → 심문 → 반전 | 추론, 접속법, 가정문 |
| **노동·인권** | **공급망 로드무비형** | 제품을 거꾸로 따라간다 (매장 → 작업장 → 창고 → 공항) | 잠입 → 증언 → 위험 | 노동 구어, 쉬운 이탈리아어를 쓰는 이주민 화자 |
| **안보** | **방첩 스릴러형** | 이중 추적. 팀은 간첩망을 쫓고, 국가 정보기관은 팀을 지켜본다 | 징후 → 추적 → 국가기밀의 벽 → 체포 | 암호·은어, 짧은 교신, 격식 공방 |
| **미디어·정보전** | **적 시점 교차형** | 홀수 화는 팀 시점, 짝수 화는 적 잠입자 시점. 후반은 팀 붕괴 | 공격 → 대응 → 붕괴 | 간접화법, 미디어 어휘 |
| **종합** | **회수형** | 이전 부의 인물·증거·분야를 모두 다시 불러 모은다 | 결집 → 대면 → 공개 | 전 시제·전 레지스터 |

## 7. 집필 규칙

1. 턴 표기는 `번호. 화자: 대사` (기존 분석 문서와 같은 형식)
2. 한 턴은 1~3문장
3. 장면마다 한국어로 **시간·장소·인물·목적**을 1~2줄 적는다.
4. 화마다 해당 부의 문법 초점이 **최소 10턴** 이상 나오게 한다.
5. **분야별 톤을 지킨다.** 사회 부는 구어와 감정, 경제는 숫자와 조건법, 정치는 완곡어법, 안보는 짧은 교신과 격식 공방.
6. **현안 처리**: 실제 사건의 구조와 쟁점만 빌려 온다. 인물·기업·국가 기관 내부 인물·구체적 혐의는 허구로 만든다. 실존 인물을 특정하지 않는다. 안보 부분에서 실제 무기 체계의 기술 정보나 공격 방법은 구체적으로 쓰지 않는다.
7. 폭력, 착취, 사보타주는 결과와 증언 중심으로 절제해서 다룬다.
