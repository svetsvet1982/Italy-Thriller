| | **le domande non sono mai diffamazione**: '질문은 명예훼손이 아니다'(77, 90턴). 이른바 *JAQ(Just Asking Questions)* 수법이다. 사라는 같은 문장을 뒤집어 되돌려 준다. |
| | **uscire dalla stessa quinta**: '같은 무대 옆으로 퇴장하다'(66턴). *quinta*는 무대 양옆의 막(윙)이다. *dietro le quinte*는 '무대 뒤에서, 막후에서'라는 뜻이다. |
